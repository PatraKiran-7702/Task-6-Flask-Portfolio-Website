# Flask Portfolio Website

## Project Overview

This project is a simple Portfolio Website developed using Python Flask. It displays personal information, skills, and includes a contact form for visitors to send messages.

## Features

* Home page with personal details
* Skills section
* Contact form
* Flask routing
* Jinja2 templates using `render_template_string`
* Simple and responsive design

## Technologies Used

* Python
* Flask
* HTML
* CSS

## Installation

1. Install Flask:

```bash
pip install flask
```

2. Run the application:

```bash
python app.py
```

3. Open your browser and visit:

```text
http://127.0.0.1:5000
```

## Project Structure

```text
portfolio/
│
├── app.py
└── README.md
```

## How It Works

* The home page displays portfolio information.
* The contact page contains a form where users can enter their name, email, and message.
* After submission, a confirmation message is displayed.
